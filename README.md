# Kwamepapaa — Celebrity Drummer Booking & Rental Automation System

**Live:** https://kwamepapa.netlify.app
**Client:** Joseph Offei (Kwamepapaa) — UEW Celebrity Drummer
**Developer:** Designed by Phil Jazzy | GCTU L100
**Type:** Client Freelance Project

### Problem
Client was spending 20 mins per client negotiating prices on phone for church programs, weddings, concerts, studio, brand promos + instrument rentals.

### Solution Built
Automated booking platform with Instant Quote Calculator.

### Core Features
1. **Services & Pricing Module**
   - Church Program GH₵250, Wedding GH₵300, Concert GH₵350, Studio GH₵200, Brand GH₵200

2. **Instrument Rental E-commerce**
   - Drums GH₵800/rental, Keyboard GH₵400, Bass GH₵400
   - "Request" buttons trigger WhatsApp with item name

3. **GET AN INSTANT QUOTE — Calculator Logic**
   - Checkbox selection, live total: GH₵800 -> GH₵1200 -> GH₵1600 -> GH₵1800
   - Logic: `total = sum(selected)` + bundle discount message if 2+ items
   - CTA: "Send Quote on WhatsApp" — generates pre-filled message: "Hi, I need Drums Rental + Keyboard... Total GH₵1600"
